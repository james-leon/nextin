# M1 — Fondations + design system (étape « /design »)

Statut : **en attente de validation de la page `/design`** avant tout écran.

## Ce qui est fait
- **Monorepo** Turborepo + pnpm : `apps/web` (Next.js 16, Tailwind v4, next-intl), `packages/shared` (rôles, téléphone E.164 +237, XAF, `APP_URL`, schémas Zod, i18n FR/EN typé, types DB générés).
- **Design system Apple HIG aligné sur la maquette Claude Design** (`design/mockups/`) : tokens clair/sombre (`app/globals.css`), 27 composants (`components/ui`), vitrine `/design` avec bascule Apparence (Auto/Clair/Sombre) et Langue (FR/EN).
  - Repris de la maquette : marque (tuile bleue à flèche), ticket `C-047` en Navy, pastilles de service colorées, sur-titre d'établissement, barre de navigation compacte, carte « Client en cours » Navy avec chrono, bouton « Terminer et appeler le suivant → », barre de progression, carte d'alerte, encart sponsorisé, viseur de scan sombre, badges statut/étiquette.
  - Section « Écrans de la maquette » : les écrans 01 à 04 reconstruits avec les composants (données fictives). 05–08 seront construits dans leurs modules (M6, M8, M2).
- **Supabase** — 4 migrations M1 :
  - socle : `profiles`, `platform_admins`, `organizations` (dont `data_retention_days` = 30), `memberships`, `invitations` ;
  - fonctions d'autorisation, RPC `create_organization`, `create_invitation`, `accept_invitation` ;
  - `audit_log` (append-only, triggers sur personnel et établissements), `rate_limits` + `check_rate_limit` ;
  - pg_cron : purge quotidienne des comptes anonymes inactifs (> 7 j), purge horaire du rate limiting.
  - Auth : connexion anonyme activée, captcha **Cloudflare Turnstile** (config Supabase) ; vérification serveur `lib/security/turnstile.ts`.
- **Auth et rôles côté app** : clients Supabase (navigateur / serveur / service role), `proxy.ts` (rafraîchit la session et protège `/app`, `/desk`, `/admin`, `/ads`), helpers `requireStaffSession`, `requireOrgRole`, `requirePlatformAdmin`. Les écrans de connexion seront construits après validation de `/design`.
- **PWA** : manifest, icônes (dont maskable), service worker maison (app shell, page hors ligne, cache statique, web push prêt pour M7).
- **CI** GitHub Actions : lint, typecheck, Vitest, pgTAP sur Supabase local, Playwright.
- **Démo** : `pnpm seed:demo` crée DOUALA CLINIC et Eneo — Douala (actifs), leur personnel et un super admin Wintek.

## Bloquants signalés
- `NEXT_PUBLIC_SUPABASE_URL`, clés, `SUPABASE_PROJECT_REF`, `SUPABASE_DB_PASSWORD`, `SUPABASE_ACCESS_TOKEN` contiennent des valeurs factices (`ton-ref`, `...`) : migrations non appliquées au distant. Valeurs à prendre dans Supabase → Project Settings → API / Database, et Account → Access Tokens.
- `NEXT_PUBLIC_TURNSTILE_SITE_KEY` / `TURNSTILE_SECRET_KEY` absentes (Cloudflare → Turnstile).
